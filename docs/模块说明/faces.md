# 表情绘制（Faces）模块说明

> **代码** `Sources/Faces/` · **测试** `Tests/FacesTests/` · **演示** `Demos/FacesDemo/` · **样张** `docs/样张/` · **归属** faces
>
> 这个模块只做一件事：给定图标矩形和一组表情参数，用纯代码（CoreGraphics，无图片素材、无第三方库）把脸画到画布上。
> 接口是 `docs/接口约定.md` 第 6 节的 `FaceRendering`，入口类型 `FaceRenderer()`，都没有改动。

## 1. 结论一览

| 项目 | 结论 | 把握 |
|---|---|---|
| 风格 | 「大眼小嘴」：眼睛是主角，嘴和眉毛平时几乎没有、情绪上来才长出来。总览代用户选定，用户回来可以改（§13） | 样张已交付；真机屏幕上的观感**待用户配合** |
| 8 种表情 | 全部实现，全由连续参数驱动；`mood` 标签只用来区分"是不是幽灵" | 测试已验证"换标签不换画面" |
| 平滑过渡 | 每个参数从 0 扫到 1（每步 0.01），画面最大的单步突变不到 1.2% | 已自动验证（§9） |
| 画到图标外面 | 只有三样：往下流的泪、Zzz、幽灵。各占一档，与强度无关；其余都在图标矩形以内 | 逐像素验证：6 种大小 × 2 种像素倍数 × 74 种状态 × 多个时刻，外加 240 组随机参数，无一越界 |
| 无状态 | 同样的输入逐像素相同；画面与图标矩形的位置无关 | 已自动验证 |
| 耗时（64 点、2x，发布版） | **平静跟随 0.029 毫秒 / 张**；最重的"眼泪直流"0.171 毫秒；全部低于 0.3 毫秒的预算 | 实测（§8）。锁屏状态下量的，量级可信 |
| 省电 | 平静、害羞、不发抖的害怕、捂眼、犯困：静止画面，返回 `nil`；睡着每秒 10 次；其余快动画每帧 | 已验证"返回 nil 的画面确实不随时间变" |
| 试玩窗口 | 能启动、约 59 帧 / 秒、限时自己退出、无残留进程；窗口自检 21 步全部通过（在进程内触发每个按钮、滑杆、开关的动作，喂鼠标位置，播完一遍连续演示）；窗口各时刻的画面已离屏渲染出来看过 | 手感**待用户配合**（§12） |

## 2. 怎么用（给总览的集成注意事项）

```swift
let renderer = FaceRenderer()                       // 结构体，无状态，可以随意拷贝、跨线程
renderer.draw(state, in: iconRect, context: context, time: time.monotonic)
let outsets = renderer.outsets(for: state, iconSize: iconRect.size)
let interval = renderer.animationInterval(for: state)
```

1. **画布状态不留痕。** `draw` 最外层成对地保存 / 恢复了绘图状态，里面的裁剪也都成对。测试检查了画完之后坐标系和裁剪范围与进来时相同。
2. **画面只看连续参数，不看 `mood`。** 唯一的例外是 `mood == .ghost`：这时只画幽灵，其它参数一律不看。
   所以情绪模块切换标签的那一帧不会跳变；标签给错了也只影响调试输出。
3. **外扩只有三档**（都向上取整到整点，同一档的画布大小始终相同）：

   | 什么时候 | 外扩 | 64 点图标上 |
   |---|---|---|
   | `tears > 0.4`（泪开始往下流） | 下方 0.25 个图标高 | 下 16 |
   | `sleepiness > 0.35`（开始冒 Zzz） | 上方约 0.22 个图标高 | 上 14 |
   | `mood == .ghost` | 上方 0.5 个图标高 + 19u（约 0.8 个图标高） | 上 51 |
   | 其它任何情况 | 无 | 0 |

   前两档可以同时出现（上 14 + 下 16）。随机参数下也只会落在这 4 种组合上（测试已验证）。
   门槛是硬切换：`tears` 从 0.40 到 0.41 的那一帧画布会换一次大小——此时泪刚冒头（又细又短），画面是连续的。
4. **`animationInterval` 的取值**（省电的依据）：

   | 状态 | 返回值 |
   |---|---|
   | 幽灵；`tremble > 0`；`dizziness > 0`；`tears > 0.4` | `0`（每帧） |
   | 只有 `sweat > 0` | `1/30` |
   | `0.05 < tears ≤ 0.4`（泪汪汪，水面微微晃） | `1/20` |
   | `sleepiness > 0.35`（Zzz、缓慢起伏） | `0.1` |
   | 其余：平静、害羞、**不发抖的害怕**、捂眼、偷看、眨眼中、犯困但没睡着 | `nil` |

   几种同时出现取最紧的。**返回 `nil` 时画面保证不随 `time` 变化**（测试用 150 组随机参数验证过），可以放心不重画。
   注意"害怕"本身是静止画面，是 `tremble`、`sweat` 让它动起来的；想让远处的邻居只是"有点怕"又不耗电，可以只给 `fear`。
5. **耗时与"每帧全部重画"**：平静跟随每张 0.029 毫秒（64 点、2x），30 张是 0.87 毫秒 / 帧，60 帧时约占一个核心的 5%；
   overlay 实测的替身脸是每张 0.11–0.14 毫秒。也就是说画脸本身不再是瓶颈，总览原计划的"限制重画频率"仍然有用但不那么紧迫。
   各表情的数字见 §8。建议仍然保留"视线取整"：瞳孔在 64 点图标上最多移动约 2.7 点，视线方向变化很小时画面几乎不变。
6. **幽灵**：`FacePlacement.rect` 给图标被删前的矩形即可，幽灵自己往上飘（中心比矩形中心高 `ghost × 一个图标高`，匀速，与接口约定一致）。
   图标在屏幕最上面一排时，幽灵会飘出屏幕上沿，被屏幕裁掉，属正常。
7. **拖拽层**：被拖着的图标用同一个接口画在 `currentImageRect` 上，没有特殊之处。
8. **色彩**：全部颜色按 sRGB 给出（`CGColor(srgbRed:…)`），与叠加层的画布一致。
9. **不合法的输入**：参数越界、非数字、矩形宽高为 0 或负数、时间非数字——都不会出事（越界值按夹回范围后的值画，空矩形不画）。
10. **线程**：不绑定线程，没有任何共享的可变状态。

### 给情绪模块的提示

- 参数的门槛：`tears` 0.05 开始泪汪汪、0.4 开始流、0.75 以上泪珠飞溅；`sleepiness` 0.35 开始冒 Zzz、约 0.94 眼睛完全闭上；`blink` 约 0.95 以上算闭上；
  `dizziness` 0.25 以下只是眼珠打转、0.7 以上完全是漩涡；`cover` 约 0.6 时手已基本到位（先快后慢）。
- `peek` 只在 `cover > 0` 时起作用；偷看时瞳孔会自动凑到指缝那里，不必另外设置视线。
- 眨眼建议 0.15–0.2 秒内 `blink` 走 0 → 1 → 0。
- 害羞的"眼神躲闪"由 `gazeTarget` 表达（看向鼠标的反方向、偏下），表情模块不替你躲。
- 一组可以直接参考的参数：`Demos/FacesDemo/ExpressionPreset.swift`（8 种表情各一组）和
  `Demos/FacesDemo/Playground/Stage.swift` 里的连续演示（拖向废纸篓 → 大哭 → 幽灵，邻居捂眼、偷看、目送）。

## 3. 风格规范

全部集中在 `Sources/Faces/FaceStyle.swift`，改风格先改那里。

**设计思路**：眼睛是主角——略高的椭圆眼眶、又大又黑的瞳孔、两点高光，看向哪里一目了然；嘴和眉毛是配角——
平时只有一个很小的微笑，没有眉毛，没有腮红；害怕、想哭时才长出八字眉，嘴才变成波浪线或张大。
这样桌面上一排平静的脸不显乱，而情绪强烈时又足够夸张。

**尺寸单位** `u` = 图标短边 ÷ 64（"64 点图标上的 1 点"）。下面的数字都是 u。

### 3.1 颜色（sRGB）

| 用途 | 色值 | 说明 |
|---|---|---|
| 墨线：眼眶、瞳孔、眉毛、嘴线、Zzz | `#221E2B` | 偏紫的近黑色，比纯黑柔和 |
| 眼白、高光、幽灵、墨线外的"贴纸边" | `#FFFFFF` | |
| 腮红 / 腮红斜线 | `#FF6B8E`（最浓时不透明度 82%）/ `#E23A64` | |
| 泪、汗的填充 / 描边 | `#C4EEFF` / `#2B8BDA` | 填充很浅，在蓝色文件夹上也比底色亮；描边较深，在浅色墙纸和白色文稿上靠它显形 |
| 张开的嘴 / 舌头 | `#6E1F35` / `#FF8FA6` | |
| 星星 | `#FFD64A`，墨色描边 | |
| 捂眼的手 | `#FFECD2`，墨色描边 | 比眼白暖一点的米色，从指缝露出来的眼白才分得清 |
| 幽灵的腮红 | `#FFB3C4` | |

**在任何图标、任何墙纸上都看得清，靠两条规则**：白色的东西（眼白、手、幽灵）都有墨色轮廓；
墨色的线（眉毛、嘴、发抖线、Zzz）外面都包一圈白边。浅色文稿、蓝色文件夹、黑色的终端图标，浅色、深色、中等亮度的底——样张里都有。

### 3.2 线宽

| 线 | 宽度 | 下限（点） |
|---|---|---|
| 眼眶轮廓 | 1.5u | 1.0 |
| 上眼皮、闭眼的线 | 2.0u | 1.25 |
| 眉毛、嘴、发抖线、Zzz | 1.6u | 1.0 |
| 墨线外的白边（每侧） | 1.0u | 0.75 |
| 泪、汗的描边 | 0.9u | 0.75 |

下限保证小图标、1x 屏上线条不会细到发虚。线头、拐角都是圆的。

### 3.3 比例

| 部位 | 数值 |
|---|---|
| 两眼所在高度 | 图标高度的 47%（从上往下） |
| 眼眶 | 半宽 7.6u、半高 8.6u；两眼之间空 4u |
| 瞳孔半径 | 平静 4.6u → 最害怕 2.0u |
| 高光 | 左上一大点（瞳孔半径的 34%），右下一小点（16%） |
| 害怕时眼睛瞪大 | 最多 +12% |
| 嘴 | 眼眶下缘往下 4.6u；平静时微笑宽 4.8u、弧度 1.7u；波浪嘴最宽 10.5u；张大时宽 10u、高 6.8u |
| 腮红 | 眼睛外下方，半宽 4.2u、半高 2.4u |
| 眉毛 | 眼眶上缘往上约 3u，最长 6.8u，内端上扬 |
| 手 | 每只约 20u × 19u：一个手掌 + 四根朝上略张开的手指 |
| 幽灵 | 宽 28u、高 34u，圆顶、下摆三道波浪 |
| 五官总宽 | 约图标宽度的 54%（32 点时 61%）——文稿图标只占矩形中间约 68% 的宽度，再宽就画到图标外面了 |

### 3.4 大小适配（32–128 点）

- 64 点以上等比放大。64 点以下五官相对放大，32 点时放大到 1.14 倍。
- 小于 44 点时省掉次要细节：第二点高光、腮红斜线、发抖线、飞溅的泪珠、第三滴汗、泪带上的第三道高光。
- 32 点 @1x 时眼睛只有约 8 个像素宽，能认出是哪种表情，但细节是粗的（见样张最下面一带）。

### 3.5 每个图标长得略有不同

由长相种子（`FaceState.seed`）决定，用的是 `SeededRandom.derive(seed, stream: 0)` 这一路，同一个种子永远相同：

| 差别 | 范围 |
|---|---|
| 眼睛大小 | ±7% |
| 两眼间距 | ±0.8u |
| 整张脸的高低 | ±1u |
| 眼睛偏长还是偏圆 | ±6% |
| 嘴的宽度 | ±15% |
| 循环小动画的相位 | 0…1（一排图标发抖、掉泪、冒 Zzz 时不整齐划一） |

情绪模块定性格请用别的路（例如 `stream: 1`），互不影响。

## 4. 每个参数的视觉含义

| 参数 | 长什么样 |
|---|---|
| `seed` | 长相的细微差别（§3.5） |
| `mood` | 只区分"是不是幽灵"。其余七种标签画面完全相同 |
| `gazeTarget` + `gazeFollow` | 瞳孔朝目标偏（每只眼睛各算各的）；整张脸也朝那边探一点（最多横 1.2u、纵 0.9u）。目标越远偏得越足；**目标就在图标上时，两眼各自朝它看，于是对眼**。`gazeFollow` 是比例，0 = 平视前方 |
| `blink` | 上、下眼皮一起合（上走 70%、下走 30%），合在中线偏下；合上后是一道微微下垂的弧线 |
| `blush` | 眼睛外下方两块腮红，越红越浓；超过 0.3 浮现三道斜线；下眼皮被顶上来一点（最多 20%）；小微笑抿成一道小波浪 |
| `fear` | 瞳孔缩小（到平时的 43%）、眼睛瞪大、长出八字眉、嘴变成波浪线并越拉越宽。连续变化，越怕越惨 |
| `sweat` | 汗珠：依次在右上、左上、右侧冒出（0 / 0.35 / 0.62 三个门槛），每滴冒出来、下滑、缩没，循环。已经在流泪时会少画一些 |
| `tremble` | 整张脸快速抖动（横向最多 1.3u）；超过 0.25 脸两侧浮现发抖线；波浪嘴开始滚动。已经在流泪时不画发抖线 |
| `tears` | 0.05 起眼眶里蓄泪（水面微微晃，高光变大）；0.4 起两道泪往下流，越流越长，流满时到图标下缘以下 8u，末端不断掉小泪珠；0.35–0.9 嘴慢慢张大成哭嚎的样子，露出舌头；0.75 以上两边眼角甩出泪珠；同时长出八字眉、下眼皮被泪顶上来一点 |
| `dizziness` | 0.25 以下眼珠打转；0.25–0.7 瞳孔缩小、漩涡从瞳孔里长出来并转动；0.2–0.6 头顶浮现三颗绕圈的星星；整张脸慢慢左右摇晃；嘴变成波浪线 |
| `cover` | 两只手从下方抬上来捂住眼睛（先快后慢，约 0.6 时已基本到位）；同时长出八字眉、嘴变成小波浪 |
| `peek` | 捂着眼时，中间两根手指往两边张开，露出一道 V 形的缝，瞳孔凑到缝里往外看。`cover` 为 0 时无效 |
| `sleepiness` | 上眼皮慢慢耷下来（0.5 时眼睛成了一只浅碗），0.8 以后下眼皮迎上去，约 0.94 合拢成一道弧线；0.35 起冒 Zzz、整张脸随呼吸缓慢起伏；0.5 起嘴变成一张小圆嘴，随呼吸微微开合 |
| `ghost` | 只在 `mood == .ghost` 时有效：一个小幽灵从图标原位匀速升起一个图标高，左右轻轻摇摆、下摆荡漾；刚冒出来时小而半透明，0.6 以后淡出，到 1 完全消失 |

**多个参数同时出现时怎么混**：嘴由四种嘴形按权重混合（哭嚎 > 波浪 > 睡着的小圆嘴 > 微笑），眉毛、眼皮各取最强的一个来源，
所以任何中间状态（害怕 0.3 + 困意 0.6……）都是成立的画面。

**情绪最强时做的减法**：流泪时不画发抖线、少画汗；小图标上省掉次要细节（§3.4）。

## 5. 八种表情

| 表情 | 典型参数 | 刷新 | 外扩 |
|---|---|---|---|
| 平静 | 只有视线和偶尔的 `blink` | 静止 | 无 |
| 害羞 | `blush`，视线躲开 | 静止 | 无 |
| 头晕 | `dizziness` | 每帧 | 无 |
| 害怕 | `fear` + `sweat` + `tremble`，死盯废纸篓 | 每帧（只给 `fear` 则静止） | 无 |
| 哭 | `tears`（+ `fear`、`tremble`） | 每帧（0.4 以下每秒 20 次） | 下 0.25 个图标高 |
| 捂眼 | `cover`（+ `peek`） | 静止 | 无 |
| 打瞌睡 | `sleepiness` | 每秒 10 次（0.35 以下静止） | 上约 0.22 个图标高 |
| 幽灵 | `mood = .ghost` + `ghost` | 每帧 | 上约 0.8 个图标高 |

样张：`docs/样张/全表情.png`。

## 6. 循环小动画

都是 `time` 的纯函数，不记任何状态；每个图标的相位由长相种子错开。

| 动画 | 节奏 |
|---|---|
| 发抖 | 横向 13 次 / 秒、纵向 17 次 / 秒 |
| 汗珠 | 每滴 1.1 秒一个循环 |
| 泪带的扭动、高光下跑 | 1.5 次 / 秒；末端的泪珠 0.55 秒掉一颗；飞溅的泪珠 0.7 秒一颗 |
| 哭嚎的嘴一张一合 | 5 次 / 秒 |
| 眼珠打转、漩涡转动、星星绕圈、头晕摇晃 | 1.1 / 1.3 / 0.6 / 0.9 圈每秒 |
| Zzz | 每个 Z 用 2.6 秒从头的右上方飘到图标上方，边飘边长大，到顶缩小淡出 |
| 睡着时的起伏 | 约 3.6 秒一次呼吸 |
| 幽灵 | 左右摇摆约 2.2 秒一个来回，下摆 0.8 次 / 秒 |

## 7. 实现结构

```
FaceRenderer   入口：保存 / 恢复画布状态，分发给幽灵或平常的脸；外扩、刷新间隔
├── FaceStyle     颜色、线宽、比例、各种门槛（改风格只改这里）
├── FacePose      姿态：把（参数、矩形、时间）算成五官的位置和大小——只有数字，不碰画布
├── FacePainter   绘制：照着姿态画
├── FaceShapes    形状：水滴、眼眶、星星、手
└── GhostPainter  幽灵
```

**为了快**，同色的东西攒成一条路径一次画完，绘制次序是：
水（泪流 + 泪珠 + 汗珠，1 次填充描边 + 1 次高光）→ 腮红 → 眼睛 → 墨线（眉毛 + 嘴 + 发抖线 + Zzz，白边和墨线各 1 次）→ 张开的嘴 → 星星 → 手。
最常见的"平静跟随"一共 5 次绘制调用，不做裁剪：眼白连轮廓 1 次、瞳孔 1 次、高光 1 次、嘴的白边和墨线各 1 次。
只有眼皮盖住一部分眼睛、或眼眶里有泪时才用一次裁剪。

**怎么保证不越界**：会靠近图标边缘的效果（汗、发抖线、星星、飞溅的泪珠、Zzz）位置都按图标矩形的比例给，不随五官的放大而外移；
会画到外面的三样，绘制和 `outsets` 用的是 `FaceStyle` 里同一组门槛和距离。

## 8. 性能数据

**怎么量的**：`swift run -c release FacesDemo --bench`。每种情形在一块离屏画布上（sRGB、y 向下、按像素倍数缩放，与叠加层给的一致）
连画 3000 次取平均，视线或时间每次都在变。机器：Apple M5，macOS 27.0.1，发布版。单位：毫秒 / 张。

| 情形 | 64 点 @2x | 64 点 @1x | 128 点 @2x | 32 点 @2x |
|---|---|---|---|---|
| **平静 · 视线跟随（最常见）** | **0.029** | 0.019 | 0.045 | 0.018 |
| 平静 · 眨眼中 | 0.022 | 0.017 | 0.033 | 0.017 |
| 害羞 100% | 0.066 | 0.049 | 0.081 | 0.048 |
| 头晕 100% | 0.150 | 0.103 | 0.190 | 0.140 |
| 害怕 50% | 0.114 | 0.073 | 0.163 | 0.069 |
| 害怕 100% | 0.128 | 0.077 | 0.188 | 0.071 |
| 哭 30%（泪汪汪） | 0.100 | 0.061 | 0.142 | 0.077 |
| 哭 100%（眼泪直流） | 0.171 | 0.069 | 0.253 | 0.113 |
| 捂眼 100% | 0.110 | 0.089 | 0.150 | 0.087 |
| 捂眼 100% + 偷看 | 0.113 | 0.092 | 0.156 | 0.091 |
| 打瞌睡 50% | 0.037 | 0.028 | 0.052 | 0.028 |
| 打瞌睡 100%（睡熟） | 0.129 | 0.107 | 0.151 | 0.134 |
| 幽灵 40% | 0.024 | 0.017 | 0.039 | 0.018 |

- 全部低于"每张约 0.3 毫秒"的预算，最重的是 128 点下的"眼泪直流"0.253 毫秒。
- 贵的都是描边多的表情（泪带、汗珠、漩涡、Zzz 的白边）。它们要么只发生在一两个图标上（被拖的那个在哭），要么刷新慢（睡着每秒 10 次）。
- 数字是在**锁屏、显示器睡眠**时量的，处理器频率可能与平时不同；多次测量之间有约 ±10% 的浮动（平静跟随量到过 0.028–0.036）。请当量级看。

## 11. 已知限制

1. **不知道图标是什么形状。** 接口只给矩形，所以所有图标的脸都在同一个位置（矩形正中偏上）。图标中间有重要内容时（比如图片的缩略图）会被眼睛盖住。
2. **颜色是固定的**，不随图标或墙纸变。在中等亮度的蓝色墙纸上，泪和汗的对比度是最弱的一种情形（靠深蓝描边显形，样张下半部分可以看到）。
3. **眼泪会盖住文件名的上半截**（流到图标下缘以下 8u，再加掉落的泪珠）。这是有意的：够夸张才好认。
4. **Zzz 和幽灵会画到上方相邻图标的位置上**（如果上面一格有图标）。
5. **32 点 @1x 下细节是粗的**：能认出表情，但线条有锯齿感；小于 44 点时次要细节被省掉。
6. **眨眼中途、犯困时的眼皮是平的**（一条水平线切过眼睛），不是弧形的。眨眼很快所以看不出来；犯困时是一只"浅碗"。
7. **眼睛合上的那一帧有一个很小的形状跳变**（从一道缝变成一条线，约占画面 1.2%）。
8. **两只手在中间是连在一起的**（两个手掌并排时轮廓合并）。
9. **长方形的图标矩形**：按短边定大小、画在矩形正中偏上，测试验证了不越界，但没有专门设计过，也没有肉眼看过。
10. **只在 macOS 27.0.1 / Apple M5 上跑过。**
11. 没有为"减弱动态效果"等辅助功能设置做适配。

## 13. 风格是怎么选的

第一阶段出了三种风格的提案（`docs/样张/风格提案.png` 和三张放大 4 倍的细节图）：

- ① 经典大眼睛：只有眼睛。最干净，视线最清楚，但情绪全靠泪、汗、腮红区分，表现力最弱。
- ② 软萌豆豆眼：小黑豆眼 + 腮红 + 小嘴。最萌，但没有眼白，"盯着鼠标"只能靠整张脸平移，核心卖点被削弱。
- ③ 大眼小嘴：本模块现在的风格。

选定 ③，并定下四处细节：平时保留那个很小的微笑；平时不带腮红（只留给害羞）；大哭时眼睛睁着、泪汪汪，不压成一横；不加眼睛下面的小影子。
**这是总览在用户不在时代为选定的，用户回来可以改选或调整。** 三种风格的出图代码都留在 `Demos/FacesDemo/Proposal/`，
`swift run FacesDemo --style-proposal` 可以随时重新出图。提案代码只画了 4 个关键表情，不是正式实现。

正式实现相对提案 ③ 的改动：瞳孔略小、活动范围更大（视线更明显）；鼠标很近时对眼更明显；眨眼和睡着的眼皮合在中线偏下；
捂眼的手、头晕、打瞌睡、幽灵是新做的；各种效果从无到有都改成了渐显。
